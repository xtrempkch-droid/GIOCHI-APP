# Colossal Cave Adventure

Jogo padrão do sistema. Original de 1976; projeto Godot 4.3 em 2,5D com
português, inglês e espanhol.

- **Runtime:** `godot`
- **Origem:** `Jogos/Colossal Cave Adventure/` no antecessor `GIOCHI-KONSOL-OS`
- **Licença:** domínio público — verifica antes de publicar

## Estado

Projeto Godot ainda **não migrado** para `src/`. Ver [docs/migracao.md](../../docs/migracao.md).

## Pendência para virar `.giochi`

Falta o **export ARM64** (template musl). Enquanto não houver export, `bin/` fica
vazio e o app não é instalável.
